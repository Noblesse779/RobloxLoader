# 🌈 Rainbow Obby 100

แมพอ็อบบี้ 100 ด่านที่สร้างเองด้วยสคริปต์ตัวเดียว ด่านไม่ซ้ำกันและยากขึ้นเรื่อย ๆ มีกระดานอันดับ ระบบขายการข้ามด่าน และเพลงประกอบ

![ภาพตัวอย่างแมพ](preview.png)

## วิธีใส่แมพลงเกม

1. เปิด **Roblox Studio** แล้วเปิดเกมของคุณ (หรือ **New → Baseplate**)
2. หน้าต่าง **Explorer** → ชี้ที่ **ServerScriptService** → กดปุ่ม **+** → เลือก **Script**
3. ลบโค้ดเดิมใน Script ออก แล้วคัดลอกโค้ด**ทั้งไฟล์**จาก [`RainbowObby.server.lua`](RainbowObby.server.lua) มาวาง
   - ถ้ามี Script ของแมพเวอร์ชันเก่าอยู่แล้ว ให้วางทับใน Script เดิมได้เลย
4. กด **Play** (F5) แมพจะถูกสร้างตอนเริ่มเกม ในหน้าต่าง Output จะขึ้นข้อความ "🌈 Rainbow Obby: พร้อมเล่นแล้ว!"

## มีอะไรในเกม

- **100 ด่าน** จากกลไก 18 แบบ ด่าน 1–18 จะได้เจอกลไกใหม่ทีละแบบ จากนั้นกลไกจะวนกลับมาในแบบที่ยากขึ้น ชื่อด่านบอกว่าเจอกลไกนั้นเป็นครั้งที่เท่าไร เช่น "คานหมุนมรณะ 3"
- **ความยาก 5 ระดับ**: ง่าย (ด่าน 1–20) → ปานกลาง → ยาก → ยากมาก → นรก (ด่าน 81–100) แท่นจะเล็กลง ช่องว่างกว้างขึ้น และสิ่งกีดขวางเร็วขึ้น ทุกช่องว่างคำนวณจากระยะกระโดดจริงของตัวละคร จึงกระโดดถึงทุกด่าน
- **จุดเซฟทุกด่าน** แท่นสีเขียวอ่อนมีตัวเลข ป้ายบนจุดเซฟบอกชื่อและความยากของด่านถัดไป
- **บันทึกความคืบหน้า** ออกเกมแล้วกลับมาเล่นต่อจากจุดเซฟเดิมได้
- **กระดานอันดับ** ในล็อบบี้ แสดง 10 คนที่ชนะมากที่สุดจากทุกเซิร์ฟเวอร์ อัปเดตทุก 1 นาที
- **ข้ามด่านด้วย Robux**: ยืนบนจุดเซฟแล้วกด **E** (บนมือถือแตะปุ่มที่ขึ้นมา) ด่านสุดท้ายข้ามไม่ได้ ต้องผ่านเอง
- **เพลงประกอบ** เล่นวนตลอดเกม
- ตกลงไปต่ำกว่าจุดเซฟเกิน 35 studs จะตายทันที ไม่ต้องรอตกถึงลาวา
- ผ่านครบ 100 ด่านแล้วเหยียบแท่นทองจะได้ +1 Win แล้วกลับไปเริ่มใหม่ที่ล็อบบี้

กลไกทั้ง 18 แบบ: กระโดดแท่น, บันไดลอยฟ้า, ทางเดินลาวา, สะพานแคบ, พื้นแก้วหายได้, ปีนหอคอย, แพลตฟอร์มเลื่อนข้าง, กระโดดเสา, กระโดดลงแม่น ๆ, คานหมุนมรณะ, เขาวงกตลาวา, สายพานไหล, ลิฟต์ลอยฟ้า, แท่นกระโดดสูง, แพข้ามเหว, กำแพงลาวากวาด, ทางเร่งความเร็ว, พื้นกะพริบ

## ตั้งค่าก่อนเปิดให้คนอื่นเล่น

ค่าที่ต้องแก้อยู่ในหัวข้อ **ตั้งค่า** ด้านบนของสคริปต์

### 1. เผยแพร่เกมและเปิดการบันทึกข้อมูล

ระบบบันทึกความคืบหน้าและกระดานอันดับต้องใช้ DataStore ของ Roblox

1. **ไฟล์ → เผยแพร่ไปยัง Roblox** (Publish to Roblox)
2. ถ้าจะทดสอบการบันทึกใน Studio: **หน้าแรก → การตั้งค่าเกม** (Game Settings) → **ความปลอดภัย** (Security) → เปิด **Enable Studio Access to API Services**

ถ้ายังไม่ได้เปิด เกมก็ยังเล่นได้ แต่จะไม่บันทึกความคืบหน้า และกระดานอันดับจะแสดงเฉพาะคนในเซิร์ฟเวอร์นั้น (ใน Output จะมีข้อความเตือนบอกวิธีแก้)

### 2. สร้างสินค้า "ข้ามด่าน"

1. เข้า [create.roblox.com](https://create.roblox.com) → **Creations** → เลือกเกมของคุณ
2. **Monetization → Developer Products → Create a Developer Product**
3. ตั้งชื่อ เช่น "ข้ามด่าน" แล้วตั้งราคา เช่น 15–25 Robux → กดบันทึก
4. คัดลอก **Product ID** มาใส่ในสคริปต์:

```lua
local SKIP_STAGE_PRODUCT_ID = 1234567890 -- เปลี่ยนเป็นเลขของคุณ
```

ระหว่างที่ยังเป็น `0` ใน Studio กด E ที่จุดเซฟจะข้ามด่านได้ฟรี ใช้ทดสอบไล่ดูทุกด่านได้เร็ว ส่วนในเกมจริงจะไม่มีปุ่มข้ามด่านจนกว่าจะใส่เลข

> ถ้าเกมมีสคริปต์อื่นขาย Developer Product อยู่แล้ว สคริปต์ที่ตั้ง `MarketplaceService.ProcessReceipt` ได้มีแค่ตัวเดียว ต้องรวมโค้ดส่วนนั้นเข้าด้วยกัน

### 3. เปลี่ยนหรือเพิ่มเพลง

เพลงเริ่มต้นคือ "Obby Music! Background Song Track Vibe" (เลข `127298405859408`) จาก Creator Store ถ้าไม่มีเสียง หรืออยากใช้เพลงอื่น:

1. เปิด **กล่องเครื่องมือ** (Toolbox) → หมวด **เสียง** (Audio) → เลือกเพลงที่ชอบ
2. คลิกขวาที่เพลง → **คัดลอก Asset ID**
3. ใส่ในรายการ ใส่หลายเพลงได้ เกมจะเล่นวนตามลำดับ:

```lua
local MUSIC_IDS = {
	127298405859408,
	1234567890, -- เพลงที่สอง
}
local MUSIC_VOLUME = 0.35 -- ความดัง 0 ถึง 1
```

ถ้าเพลงไหนโหลดไม่ได้ ใน Output จะมีข้อความบอกเลขเพลงนั้น

## ปรับแต่งเพิ่มเติม

| ค่า | ความหมาย |
|---|---|
| `STAGE_COUNT` | จำนวนด่าน (ค่าเริ่มต้น 100) |
| `STAGES_PER_ROW` | จำนวนด่านต่อแถวก่อนเลี้ยวกลับ |
| `MAP_SEED` | เปลี่ยนเลขนี้แล้วด่านจะหน้าตาเปลี่ยนไปทั้งชุด (จุดเซฟที่ผู้เล่นบันทึกไว้จะไม่ตรงกับด่านเดิม ควรเปลี่ยน `SAVE_NAME` ด้วย) |
| `SAVE_NAME` | ชื่อที่ใช้บันทึกข้อมูล เปลี่ยนเมื่ออยากล้างความคืบหน้าและอันดับของทุกคน |

## อยากแต่งแมพเองใน Studio

ปกติแมพจะถูกสร้างตอนกด Play เท่านั้น ถ้าอยากเห็นและแก้ในหน้าแก้ไข:

1. กด **Play** ให้แมพถูกสร้างก่อน
2. ใน Explorer คลิก **Workspace → RainbowObby100** แล้วกด **Ctrl+C**
3. กด **Stop**
4. คลิก **Workspace** แล้วกด **Ctrl+V**

สคริปต์จะเห็นโฟลเดอร์ `RainbowObby100` ที่มีอยู่แล้ว และใช้แมพนั้นแทนการสร้างใหม่ หน้าที่ของแต่ละชิ้นกำหนดด้วย **Attributes** (ดูได้ในหน้าต่าง Properties) เพิ่มให้ Part ของตัวเองได้เลย:

| Attribute | ชนิด | ผล |
|---|---|---|
| `Kill` | boolean = true | โดนแล้วตาย |
| `Checkpoint` | number | เป็นจุดเซฟลำดับตามตัวเลขนั้น (ต้องเรียง 1, 2, 3, … ไม่ข้ามเลข) |
| `Fade` | boolean = true | พื้นจางหายหลังเหยียบ (`FadeDelay` = กี่วินาทีก่อนหาย) |
| `JumpBoost` | number | เหยียบแล้วกระโดดได้สูงตามค่านี้ 3 วินาที |
| `SpeedBoost` | number | เหยียบแล้ววิ่งเร็วตามค่านี้ 3 วินาที |
| `Finish` | boolean = true | แท่นชนะ (ต้องผ่านจุดเซฟเลขสูงสุดก่อน) |
